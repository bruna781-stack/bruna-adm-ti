Fontes

  • IBGE. PNAD Contínua — agregados 7395, 7113, 7126 e 7138, 2025. API de Agregados v3.
  • IBGE. Projeções da População — Revisão 2024 — esperança de vida ao nascer, 2025. Página oficial.
  • IBGE. Malha territorial — API v3 de malhas, UFs.
  • Banco Mundial. PPP conversion factor, GDP (LCU per international $) — PA.NUS.PPP, Brasil, 2025.
  • PNUD/Ipea/FJP. Atlas do Desenvolvimento Humano no Brasil — IDHM oficial. atlasbrasil.org.br.
  • Ipea. IpeaData — séries IDHM, IDHMED, IDHMLO, IDHMRE e PNUD_IDH. API OData v4.

Reproduzir

Na raiz do repositório:

python .opencode/skills/analise-idh-ibge/coleta_ipea.py
python .opencode/skills/analise-idh-ibge/gera_mapa_idh.py
python .opencode/skills/site-idh-ibge/gera_site.py
python .opencode/skills/site-idh-ibge/servir.py

O primeiro comando baixa o IDHM oficial; o segundo coleta o IBGE e gera o mapa autocontido; o terceiro monta este site; o quarto sobe um servidor local em http://localhost:8000.

Parâmetros da estimativa: INPC médio de 2010 = 3206,17, INPC médio de 2025 = 7487,45, PPP = 2,5544. Dados gerados em 2026-11-03.

Elaboração própria. IDH estimado 2025 (IBGE) e IDHM oficial 2024 (Atlas/IpeaData) são indicadores distintos — compare apenas dentro da mesma camada.
