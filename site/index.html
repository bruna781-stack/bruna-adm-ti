Duas camadas: IDH estimado 2025 com dados do IBGE e IDHM oficial 2024 do Atlas, obtido pela API do IpeaData.

Visão geralEstadosComparaçãoMetodologiaDados
Leia antes de citar: o IBGE não calcula nem publica IDH/IDHM. O IDH estimado 2025 é uma estimativa própria, feita com componentes oficiais do IBGE, adequada para comparar estados entre si. O IDHM oficial 2024 vem do Atlas do Desenvolvimento Humano (PNUD/Ipea/FJP), obtido pela API do IpeaData. São índices diferentes: não compare um valor da camada estimada com um valor oficial.
